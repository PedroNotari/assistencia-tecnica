# Assistência Técnica

Sistema de gerenciamento de uma assistência técnica desenvolvido em Java.

# Sobre o projeto

O projeto está sendo desenvolvido como forma de praticar programação em Java e conceitos de Programação Orientada a Objetos.
A ideia é evoluir o sistema gradualmente, adicionando novas funcionalidades e melhorias conforme o desenvolvimento avança.

# Funcionalidades atuais

- Cadastro de clientes
- Cadastro de técnicos
- Abertura de ordens de serviço
- Associação de clientes e técnicos às ordens
- Data automática de abertura
- Listagem de clientes
- Listagem de técnicos
- Listagem de ordens de serviço

# Tecnologias

- Java
- Eclipse
- Git
- GitHub
